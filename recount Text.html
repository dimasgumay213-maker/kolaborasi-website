MY EXPERIENCE
CREATING A
WEBSITE

Last month, I created my own portfolio website to improve my web development skills and show my personal projects. The website was designed with a modern dark theme and included several sections such as Home, About Me, Projects, Blog, and Contact.

At the beginning, I planned the layout and searched for design inspiration. After that, I started coding the website using HTML and CSS for the structure and design. I also used JavaScript to make the website more interactive and responsive.

One of the most challenging parts was arranging the layout so it looked clean and professional on both mobile and desktop screens. I spent a lot of time fixing margins, colors, and animations to make the user experience better. Besides that, I added my personal photo, social media icons, and information about my skills and experience.

After finishing the project, I felt very proud because the website looked modern and attractive. Through this experience, I learned many new things about web development, especially about responsive design and user interface design. This project also motivated me to continue learning programming and become a better developer in the future.
